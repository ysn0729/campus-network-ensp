# 03 · 关键技术验证记录

每条验证都按「命令 → 预期输出 → 判读依据」记录，便于复现时对照。

---

## 1. 双核心 VRRP 网关冗余

**命令**

```
display vrrp
display vrrp brief
```

**预期输出（Core-SW1）**

```
Vlanif10 | Virtual Router 10
  State            : Master
  Virtual IP       : 10.10.10.254
  Master IP        : 10.10.10.1
  PriorityRun      : 120
  Preempt          : YES  Delay Time : 20s
  Track Interface  : GigabitEthernet0/0/2  reduced 30
```

**判读**：`State: Master` + `Virtual IP` 与规划一致 + `Track` 指向真实上联口；Core-SW2 上同一 VR 应为 `Backup`。

**切换验证**：断开 Core-SW1 上行口，再执行 `display vrrp brief`，Core-SW2 应在 20 秒抢占延迟后变 Master，终端 `ping` 出现少量丢包后恢复。

## 2. MSTP 多实例负载分担

**命令**

```
display stp instance 1 brief
display stp instance 2 brief
display stp root
```

**判读**：instance 1 中 Core-SW1 为 ROOT、Core-SW2 为 ALTE；instance 2 相反。接入侧端口全部 `FORWARDING`（终端口为 edged-port，不参与收敛）。

> 两台核心互为不同实例的根桥，才能把「一半 VLAN 走 SW1、一半走 SW2」这件事落到实处。

---

## 3. OSPF 与 BFD 联动

**命令**

```
display ospf peer brief
display bfd session all
display ospf bfd session all
```

**判读**：核心与防火墙之间 OSPF 邻居 `Full`；BFD 会话状态 `Up`，检测时间在毫秒级。

**故障验证**：`shutdown` 互联口后，BFD 先于 OSPF 的 Hello 超时感知，邻居立即 Down，路由表在 1 秒内完成收敛（对比未开 BFD 时需 40 秒）。

---

## 4. 防火墙 HRP 双机热备

**命令（FW1 / FW2 各执行一次）**

```
display hrp state
display hrp interface
display vrrp
```

**判读**：

- FW1 提示符为 `HRP_M[FW1]`、`display hrp state` 显示 `Role: active`；
- FW2 提示符为 `HRP_S[FW2]`、角色 `standby`；
- `display hrp interface` 指向 `GigabitEthernet1/0/3 remote 10.255.255.2`；
- 内网侧 VRRP 虚拟 IP `10.255.1.6` 由主设备承载。

**切换验证**：在主设备 `shutdown` GE1/0/1（跟踪的出口口），主备应在秒级完成切换，内网访问不中断（会话表已镜像）。

## 6. 无线：AP 上线与 VAP 下发

**命令（AC-1）**

```
display ap all
display vap ssid all
display station all
```

**预期输出**

```
display ap all：
  AP ID  AP Name  AP MAC          Type    State  STA  ...
  1      AP-1     00e0-fc4b-4ba0  AP6050  nor    1
```

`display vap ssid all` 中应能看到 `HOSPITAL-MED` 与 `HOSPITAL-GUEST`，`Total` 等于 AP 数 × 射频数 × SSID 数。

```        
display station all：
  MAC             AP    RF  Band  SSID           IP           VLAN
  5489-989e-7d8f  1     0   2.4G  HOSPITAL-MED   10.10.50.253 50
```

**判读**：STA 的 VLAN 为 50、IP 落在 10.10.50.0/24，说明「SSID → VAP → 隧道 → 核心 VLANIF」整条链路通。

## 7. 端到端业务验证

| 验证项 | 命令/操作 | 结果 |
|---|---|---|
| 无线终端跨网段 | STA `ping 10.10.200.12` | 0% 丢包，ttl=254 |
| 域名解析 + HTTP | Client 访问 `http://his.hospital.local/index.html` | 200 OK，Content-Length 3125 |
| 影像下载 | Client FTP 连 `10.10.200.12`，下载 README | 文件下载成功，字节数一致 |
| 访客隔离 | 访客终端 `ping 10.10.200.12` | 超时（ACL 3040 生效） |

> `ping` 网关 `.254` 在 eNSP 中会提示 unreachable，这是 VRRP 虚拟 IP 不响应 ICMP 的平台现象，不代表网关不可用——用 ping 服务器验证更有意义。
