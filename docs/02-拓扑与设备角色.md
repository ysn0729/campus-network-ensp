## 3. 接入层端口规划

以 Access-1A 为例（其余接入交换机同构）：

| 端口 | 类型 | VLAN | 连接 | 附加配置 |
|---|---|---|---|---|
| GE0/0/1 | trunk | 10, 100 | 上联 Agg-SW1 | `dhcp snooping trusted` |
| GE0/0/2 | access | 100 | AP-1 | 供电 + 管理网段 |
| GE0/0/3 | access | 10 | PC-病区A | `stp edged-port`、端口隔离 |
| GE0/0/4 | access | 10 | Client1（测试机） | `stp edged-port`、端口隔离 |

要点：

- **只有上联口是 trusted**。接入层开启了 DHCP Snooping，若把下联口也设成 trusted，等于关掉了防私接 DHCP 的作用；
- 终端口开 `stp edged-port`，避免终端开关机触发 STP 重新收敛；
- 终端口开端口隔离，抑制同 VLAN 内终端互访（医院场景下可减少蠕虫横向扩散）；
- 终端口**不开** `dot1x` 与 `ip source check user-bind`（IPSG）——静态 IP 终端没有 DHCP 绑定表，开了会被直接丢包。

## 4. 无线部分

- AC-1 旁挂，管理地址 `10.10.100.31`，`capwap source interface Vlanif100`；
- AP 采用 MAC 认证上线（`ap auth-mode mac-auth`），三台 AP 的桥 MAC 预先在 AC 登记，注册后自动加入 `ap-group HOSPITAL`；
- 射频统一在国家码 `cn` 下：2.4G 信道 1（20MHz），5G 信道 149（20MHz）；
- 两个 VAP：`MED_VAP`（SSID `HOSPITAL-MED`，VLAN50）、`GUEST_VAP`（SSID `HOSPITAL-GUEST`，VLAN40），均为 tunnel 转发；
- 安全模板：`MED_WPA2` 为 WPA2-PSK/AES（仿真环境无 RADIUS，设计目标态为 802.1X），`GUEST_OPEN` 为开放认证。

## 5. 防火墙

| 接口 | 地址 | 区域 |
|---|---|---|
| GE1/0/1 | 202.101.1.2/30（FW2：202.102.1.2/30） | untrust |
| GE1/0/2 | 10.255.1.1/29（FW2：10.255.1.4/29） | trust |
| GE1/0/3 | 10.255.255.1/30（FW2：.2/30） | HRP_ZONE（自定义，优先级 60） |

- `dmz` 区域已定义但当前无接口挂载，为后续对外发布服务预留；
- HRP：`hrp interface GE1/0/3 remote <对端>`、`hrp track interface GE1/0/1`（跟踪出口，出口断则切换）、`hrp mirror session enable`（会话表镜像，切换不断流）；
- 策略：`trust_to_untrust permit` + 源 NAT（地址池 202.101.1.2）；
- 主设备提示符显示 `HRP_M[FW1]`，备机为 `HRP_S[FW2]`，可直接截图作为双机热备生效的证据。
