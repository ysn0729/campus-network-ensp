# 01 · 地址规划与 VLAN 设计

## 1. 划分依据

医院业务按**使用场景 + 安全等级**划分 VLAN，而不是按楼层。理由：

- 同一科室的终端分布在不同楼层，按楼层划 VLAN 会导致跨楼层二层广播域过大、故障域扩散；
- 等保 2.0 三级要求对「内网业务区 / 办公区 / 访客区 / 管理区」做边界隔离，按业务划分更容易在防火墙上做策略。

最终划出 7 个业务 VLAN：

| VLAN | 名称 | 网段 | 网关(VIP) | 承载 |
|---|---|---|---|---|
| 10 | MED_ZY | 10.10.10.0/24 | 10.10.10.254 | 病区护士站、医生工作站 |
| 20 | MED_MZ | 10.10.20.0/24 | 10.10.20.254 | 门诊、诊室终端 |
| 30 | OFFICE | 10.10.30.0/24 | 10.10.30.254 | 行政办公 |
| 40 | GUEST | 10.10.40.0/24 | 10.10.40.254 | 访客无线（隔离） |
| 50 | WLAN_MED | 10.10.50.0/24 | 10.10.50.254 | 移动护理车、PDA |
| 100 | MGMT | 10.10.100.0/24 | 10.10.100.254 | 网络设备管理、AP 管理 |
| 200 | SERVER | 10.10.200.0/24 | 10.10.200.254 | HIS / PACS / DB / LOG |

## 2. 网关与冗余

每台核心交换机都起全部 7 个 VLANIF，用 VRRP 提供统一网关 `.254`，避免终端改网关：

- **Core-SW1**：VLAN10/20/50/100/200 为主（`priority 120`），30/40 为备；
- **Core-SW2**：VLAN30/40 为主，其余为备；
- 抢占延迟 `preempt delay 20`，防止链路抖动时来回切换；
- 上行口 `track` 联动，上行断开时自动降优先级，让流量切到对端核心。

配合 MSTP 多实例（instance 1 / instance 2，两台核心互为主备），做到**二层负载分担 + 三层网关冗余**同时成立，避免「所有流量都绕一台核心」。

## 3. 服务器区

| 主机 | 地址 | 作用 |
|---|---|---|
| SRV-HIS | 10.10.200.11 | 医院信息系统（HTTP 演示页） |
| SRV-PACS | 10.10.200.12 | 影像归档（FTP 影像库） |
| SRV-DB | 10.10.200.13 | 数据库 + DNS |
| SRV-LOG | 10.10.200.14 | 日志审计 |

全网的 DNS 统一指向 `10.10.200.13`，由它解析 `his.hospital.local` 等内部域名。

## 4. DHCP 分工

两台核心各自跑一半地址池，互为备份：

| 地址池 | 所在设备 | 网关 |
|---|---|---|
| vlan10 / vlan20 / vlan50 / vlan100 | Core-SW1 | 对应 VLANIF VIP `.254` |
| vlan30 / vlan40 | Core-SW2 | 对应 VLANIF VIP `.254` |

固定地址（服务器、AP、网络设备）在同一网段内从池中排除，避免地址冲突。

## 5. 互联地址

| 链路 | 网段 | 说明 |
|---|---|---|
| 核心 ↔ 防火墙 | 10.255.1.0/29 | Core-SW1 `.2`、Core-SW2 `.3`、FW1 `.1`、FW2 `.4`，VRRP VIP `10.255.1.6` |
| FW1 ↔ FW2 | 10.255.255.0/30 | HRP 心跳 `10.255.255.1` / `.2` |
| FW1 ↔ ISP | 202.101.1.0/30 | ISP `GE0/0/0` = 202.101.1.1，FW1 `GE1/0/1` = 202.101.1.2 |
| FW2 ↔ ISP | 202.102.1.0/30 | ISP `GE0/0/1` = 202.102.1.1，FW2 `GE1/0/1` = 202.102.1.2 |

双运营商出口分别接两台防火墙，单侧出口故障时由 HRP 切换，内网无感知。

## 6. 无线地址

无线采用 **tunnel 转发**：AP 只做二层桥接，业务流量统一由 AC 封装到隧道，再回到核心。因此**终端拿哪个网段只取决于 SSID 绑定的 VLAN，与 AP 所在楼层无关**：

- `HOSPITAL-MED` → VLAN 50 → 10.10.50.0/24
- `HOSPITAL-GUEST` → VLAN 40 → 10.10.40.0/24

这一点在排障时很关键：STA 拿到 10.10.50.x 而不是 AP 管理网段地址，说明隧道与 VAP 都正常。
